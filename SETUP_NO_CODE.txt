TURK SETTINGS - KEYAUTH LOGIN

ไฟล์นี้ทำไว้ให้ใช้กับ GitHub Pages + Cloudflare Worker
ผู้ใช้ไม่ต้องเขียนโค้ดใหม่

1) สร้าง Cloudflare Worker ชื่ออะไรก็ได้
2) เอาเนื้อหาใน worker.js ไปใส่ใน Worker แล้วกด Deploy
3) ที่ Worker > Settings > Variables and Secrets เพิ่ม:

KEYAUTH_APP_NAME = ชื่อ Application ใน KeyAuth
KEYAUTH_OWNER_ID = Owner ID ของ Application ใน KeyAuth
ALLOWED_ORIGIN = https://turkuserz.github.io

อย่าใส่ Seller Key หรือคีย์ License ลงใน Worker หรือ GitHub

4) หลัง Deploy จะได้ URL ประมาณ:
https://ชื่อ-worker.ชื่อผู้ใช้.workers.dev

5) เปิดไฟล์ auth-config.js แล้วเปลี่ยนแค่ URL บรรทัดเดียวเป็น:
window.TURK_AUTH_URL = 'https://ชื่อ-worker.ชื่อผู้ใช้.workers.dev/verify';

6) อัปโหลดไฟล์ทั้งหมดกลับ GitHub Pages

หน้า Login จะทำงานแบบนี้:
กรอก Key -> กด LOGIN -> Worker -> KeyAuth -> ผ่านจึงเข้า Dashboard
ถ้าเกิน 5 วินาทีจะหยุดเอง ไม่ค้าง

Key ที่ผู้ใช้กรอกเป็น password field จึงไม่แสดงบนหน้าจอ
ไม่มีการใส่ License ตัวอย่างไว้ในไฟล์

KeyAuth ใช้ license login ผ่าน endpoint type=license หลังจาก init session ก่อน
อ้างอิงเอกสารทางการ: https://docs.keyauth.cc/api/getting-started/license/license-login
