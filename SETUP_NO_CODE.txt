TURK SETTINGS - KEYAUTH SETUP

ปัญหาที่เกิดตอนนี้: หน้า GitHub ของคุณยังไม่ได้เชื่อม URL ของ Cloudflare Worker จึงตรวจ KeyAuth ไม่ได้

ทำตามนี้:
1. เข้า Cloudflare Dashboard > Workers & Pages > Create > Worker.
2. เปิด Worker แล้วเลือก Edit code.
3. ใช้ไฟล์ worker.js ที่อยู่ใน ZIP นี้แทนโค้ดเดิม แล้ว Deploy.
4. ไปที่ Settings > Variables and Secrets ของ Worker แล้วสร้างตัวแปร:
   KEYAUTH_APP_NAME = ชื่อ Application ใน KeyAuth
   KEYAUTH_OWNER_ID = Owner ID ของ Application
   ALLOWED_ORIGIN = https://turkuserz.github.io
5. กลับมาที่ไฟล์ auth-config.js ใน ZIP นี้ แล้วเปลี่ยน YOUR-WORKER เป็น URL Worker ของคุณ โดยต้องลงท้าย /verify
6. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub Pages ใหม่

หน้า Login จะทำงานแบบ:
ใส่ Key > ส่งไป Worker > Worker ตรวจ KeyAuth > ผ่านจึงเปิด Dashboard

ถ้าเกิน 5 วินาทีจะหยุดตรวจและให้กดใหม่ ไม่ค้าง

หมายเหตุ: License ที่สร้างใน KeyAuth ต้องเป็น License ของ Application เดียวกับ KEYAUTH_APP_NAME/OWNER_ID และถ้าเป็น License Login ครั้งแรก KeyAuth จะเปลี่ยน License เป็น user ตามระบบของ KeyAuth.
